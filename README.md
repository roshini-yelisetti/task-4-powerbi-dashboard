# Financial Sales Dashboard - Power BI

## Project Overview
This project focuses on designing an interactive Power BI dashboard for business stakeholders using a Financial Sales Dataset from Kaggle.

## Objective
To analyze financial sales data and create a dashboard that helps businesses make data-driven decisions through visual insights and key performance indicators (KPIs).

## Dataset
- Dataset Name: Financial Dataset Sample
- Source: Kaggle
- Records: 700
- Columns: 16

## Tools Used
- Power BI Desktop
- Microsoft Excel
- GitHub

## Dashboard Features
### KPI Cards
- Total Sales
- Total Profit
- Units Sold
- Total Discounts
- Growth Percentage

### Visualizations
- Sales by Country
- Profit by Product
- Monthly Sales Trend
- Sales by Segment

### Interactive Filters
- Country
- Product
- Segment
- Year

## Key Insights
- United States generated the highest sales.
- Paseo was the most profitable product.
- Government segment contributed the highest revenue.
- Sales showed positive growth over time.
- Interactive filters allow detailed business analysis.
